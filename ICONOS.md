# Instrucciones para los iconos

Para que tu extensión tenga iconos adecuados, necesitas crear o descargar tres imágenes PNG con los siguientes tamaños:

1. `icon16.png` - 16x16 píxeles
2. `icon48.png` - 48x48 píxeles
3. `icon128.png` - 128x128 píxeles

## Opciones para obtener iconos

### Opción 1: Crear iconos personalizados
Puedes usar herramientas como Adobe Photoshop, GIMP, o Canva para crear tus propios iconos.

### Opción 2: Descargar iconos gratuitos
Puedes descargar iconos gratuitos de sitios como:
- [Flaticon](https://www.flaticon.com/) - Busca "youtube subscribe" o "youtube channel"
- [Icons8](https://icons8.com/) - Tiene muchos iconos relacionados con YouTube
- [Iconmonstr](https://iconmonstr.com/) - Ofrece iconos simples y elegantes

### Opción 3: Usar un favicon generador
Puedes usar herramientas en línea como:
- [Favicon.io](https://favicon.io/) - Permite crear iconos a partir de texto o imágenes
- [RealFaviconGenerator](https://realfavicongenerator.net/) - Genera iconos en múltiples tamaños

## Instrucciones para reemplazar los archivos

1. Una vez que tengas tus iconos, asegúrate de que tengan los nombres correctos:
   - `icon16.png`
   - `icon48.png`
   - `icon128.png`

2. Coloca estos archivos en la carpeta `images` de tu extensión, reemplazando los archivos vacíos que se crearon inicialmente.

## Sugerencia de diseño

Para mantener la coherencia con YouTube, considera usar:
- Fondo rojo (#FF0000)
- Icono de "suscribirse" o "campana" en blanco
- Diseño simple y reconocible
